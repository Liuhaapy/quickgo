# WPS 表单定时提交：零基础操作教程

> 目标：提前把浏览器和答案准备好，到 12:40:00 由脚本点击提交。
>
> 你不需要懂 Python，也不需要打开命令行。只按顺序双击带数字的 `.bat` 文件即可。

---

## 先认识三个东西

1. **文件夹**：就是现在这个 `default-workspace` 文件夹，所有文件都在这里。
2. **黑色窗口**：双击 `.bat` 后会弹出一个黑色命令行窗口。**不要关它**，按窗口里的提示操作。
3. **Edge 浏览器**：脚本会自动打开 Edge。你需要在这里扫码登录、完成滑块。

整个流程分两段：

- **现在**：测试环境、改配置、填答案、演练。
- **当天**：提前打开，登录，按 Enter，然后不要碰电脑。

---

## 第 0 步：先做安装自检

双击：

**`5-测试本地表单.bat`**

这个测试不联网，不会碰你的真实表单。

等待约 10 秒，黑色窗口里出现下面内容就说明环境正常：

```text
提交成功。
Done. Press any key to close this window.
```

按任意键关闭窗口。

如果这里就报错，把黑色窗口最后 10 行发给我，不要继续后面的步骤。

---

## 第 1 步：填表单地址和提交时间

双击：

**`1-修改配置.bat`**

会弹出记事本，里面是 `config.json`。第一次打开时，会自动备份一份 `config.backup.json`。

只改这两个地方：

```json
"form_url": "这里换成你的 WPS 表单链接",
"submit_at": "12:40:00"
```

### 怎么复制表单链接

1. 用 Edge 打开你的 WPS 表单；
2. 点一下浏览器最上面的地址栏；
3. 按 `Ctrl + A` 全选；
4. 按 `Ctrl + C` 复制；
5. 回到记事本，把链接粘贴到 `form_url` 的英文双引号里面。

### 时间怎么写

保持这种格式：

```json
"submit_at": "12:40:00"
```

改完按 **Ctrl + S** 保存，再关闭记事本。

### 注意

- 只改英文双引号 **里面** 的字。
- 不要删除引号、逗号、大括号。
- 如果改坏了，双击 `0-恢复配置.bat` 可以恢复到第一次打开时的备份。

---

## 第 2 步：让脚本认识你的题目

双击：

**`2-查看页面控件.bat`**

接下来：

1. Edge 会自动打开你的表单；
2. 如果需要登录，先扫码登录、完成滑块；
3. 确认题目已经显示出来；
4. 回到黑色窗口，按一次 **Enter**；
5. 窗口会打印出页面上所有输入框、选项、按钮的信息。

你会看到类似这样的内容：

```text
#00 <INPUT type='text'> placeholder='请输入姓名' => 可尝试 [placeholder*='请输入姓名']
#02 <INPUT type='radio'> label='一班' => 可尝试 label:has-text('一班')
#09 <BUTTON> text='提交' => 可尝试 #submitBtn
```

看到这些信息后，你有两个选择：

### 选择 A：最省事

把黑色窗口里的内容复制发给我，我帮你把 `config.json` 里的字段和选择器填好。

### 选择 B：自己填

把“可尝试”后面的选择器，填到 `config.json` 对应字段的 `selector` 里。

不会填也没关系，直接选 A。

## 第 3 步：填答案

再次双击：

**`1-修改配置.bat`**

找到 `fields` 部分，改答案。

### 填空题

```json
"value": "你的答案"
```

例如：

```json
"value": "张三"
```

### 单选题

```json
"option": "你要选的选项"
```

例如：

```json
"option": "一班"
```

### 多选题

```json
"options": ["选项1", "选项2"]
```

例如：

```json
"options": ["阅读", "跑步"]
```

只改引号里的内容，不要改外面的结构。

改完按 **Ctrl + S** 保存。

---

## 第 4 步：先演练“只填表，不提交”

双击：

**`3-只填表不提交.bat`**

接下来：

1. Edge 打开表单；
2. 扫码登录、完成滑块；
3. 回到黑色窗口按 **Enter**；
4. 脚本自动填表；
5. 填完会截图，然后退出，**绝对不会提交**。

截图在 `artifacts` 文件夹里，打开最新的那张，检查：

- 姓名、学号对不对；
- 单选、多选有没有选中；
- 备注有没有填上。

如果有错，回到第 3 步改答案，再运行一次 `3-只填表不提交.bat`。

---

## 第 5 步：正式提交

双击：

**`4-正式提交.bat`**

接下来：

1. Edge 打开表单；
2. 扫码登录、完成滑块；
3. 回到黑色窗口按 **Enter**；
4. 脚本等到目标时间前 **1 秒**，自动刷新一次表单页面；
5. 刷新后脚本重新填表，然后继续等待；
6. **之后不要碰鼠标和键盘**；
7. 到 12:40:00，脚本自己点击提交；
8. 看到“提交成功”后，截图会保存在 `artifacts`。

### 自动刷新说明

`4-正式提交.bat` 里有一行：

```bat
set REFRESH_BEFORE=1
```

意思是“提交前 1 秒刷新页面”。如果 WPS 页面加载慢、提交时间偏晚，可以把 `1` 改成 `2` 或 `3`；不想刷新就改成 `0`。

刷新会清空页面上已有的内容，然后脚本会重新填写，所以刷新后不要手动输入。

### 如果看到“字段暂未开放”

这是正常的，说明表单还没到开放时间。

`4-正式提交.bat` 已经自动带 `--fast-open`：脚本会等页面自己解除 `disabled`，然后快速填写并提交。

**不要关窗口，也不要手动去改网页。**

浏览器如果弹出 `alert` / `confirm` 原生弹窗，脚本会自动点“确定”，不会再自动取消。

## 出问题怎么办

| 你看到的 | 原因 | 怎么办 |
|---|---|---|
| 提示“请先把 config.form_url 换成真实地址” | 还没改表单链接 | 回到第 1 步 |
| 提示“仍然是示例答案 请填写” | 答案还是模板 | 回到第 3 步 |
| 提示“找不到提交按钮” | 按钮选择器不对 | 用 `2-查看页面控件.bat` 看按钮，填 `submit_button` |
| 提示“字段暂未开放” | 正常，等页面开放 | 不要关窗口 |
| 黑色窗口一闪而过 | 可能双击了 `run.ps1` 或 `.py` 文件 | 改双击带数字的 `.bat` |
| 提示 JSON 格式错误 `Expecting...` | 配置改坏了 | 双击 `0-恢复配置.bat` |
| 页面停在登录页 | 登录态过期 | 扫码登录 |
| 提交失败/结果未知 | 看截图和日志 | 不要重复运行，先确认是否已提交 |
| 找不到 `artifacts` | 还没运行过 | 运行 `3` 或 `4` 后会自动生成 |

日志文件：`wps_auto_submit.log`

## 绝对不要做的事

1. **不要提前手动点提交**。脚本会自己点。
2. **不要同时双击两次** `4-正式提交.bat`，可能重复提交。
3. **不要用开发者工具去改 `disabled`**。脚本不会这样做，也不建议你这样做。
4. **不要删除** 这三个东西：
   - `.deps`
   - `.venv`
   - `.wps_profile`（保存登录状态）
5. **不要在脚本运行时重启电脑或关闭黑色窗口**。
